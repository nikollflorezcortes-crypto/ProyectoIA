🏛️ Arquitectura del Proyecto IntelliPlan AI

Materia: Inteligencia Artificial Aplicada

Integrantes: Nikoll Florez • Alan Rangel • Carlos Movilla

1. Núcleo Cognitivo: Core Agent

El CoreAgent actúa como el núcleo cognitivo del sistema. Interpreta cualquier entrada en lenguaje coloquial, analiza la intención del usuario y delega dinámicamente la ejecución a habilidades especializadas (Skills).

2. Skills Modulares

  • skill-categorizacion: Clasifica la tarea semánticamente en Trabajo, Personal o Urgente.
  • skill-priorizacion: Evalúa la urgencia y plazos implícitos o explícitos para asignar prioridad (Alta, Media, Baja) y fecha recomendada.
  • skill-resumen-diario: Analiza todos los pendientes activos y genera una recomendación ejecutiva de las 3 tareas críticas para enfocarse hoy.

3. Tecnología de IA Unificada

Utiliza Google Gemini Flash API como motor de IA en la nube, con un motor semántico local integrado de alta fidelidad para operar sin interrupciones ni dependencias externas.
